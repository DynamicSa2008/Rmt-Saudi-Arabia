# قالب رفال المدينة (RMT) – ووردبرس

تطوير: فريق شركة داينمك – dynamic-sa.com

## التثبيت
1. ارفع مجلد `rmt` إلى `wp-content/themes/`، أو ارفع ملف `rmt-theme.zip` من: المظهر ← قوالب ← إضافة جديد ← رفع.
2. فعّل القالب. سيتم تلقائيًا:
   - إنشاء الصفحات الخمس: الرئيسية، من نحن (`/about`)، خدماتنا (`/services`)، عملاؤنا (`/clients`)، اتصل بنا (`/contact`).
   - ضبط الرئيسية كصفحة ثابتة، والروابط الدائمة `/%postname%/`، والمنطقة الزمنية Asia/Riyadh.
3. من القائمة الجانبية افتح **لوحة رفال**. تبدأ الجولة التفاعلية تلقائيًا في أول زيارة.

## النسخة الإنجليزية
- الصفحات الإنجليزية تُنشأ تلقائيًا تحت `/en/` (`/en/about/`، `/en/services/`…) مع وسوم hreflang بين النسختين.
- من لوحة رفال اضغط **English** لتعديل نصوص الإنجليزي. الصور والأرقام والروابط مشتركة.

## الخريطة (موقع دقيق)
لوحة رفال ← البيانات العامة ← **كود تضمين الخريطة**: من Google Maps افتح الموقع ← مشاركة ← تضمين خريطة ← نسخ HTML والصقه. الإحداثيات تُستخرج تلقائيًا للسيو.

## وصول طلبات التواصل على الإيميل (مهم)
لوحة رفال ← التواصل والنموذج ← **إعدادات إرسال الإيميل (SMTP)**:
- **Gmail** (rafalalmadinah@gmail.com): السيرفر `smtp.gmail.com`، المنفذ `587`، التشفير TLS، والمستخدم هو البريد كاملًا، وكلمة المرور = **كلمة مرور التطبيقات** (حساب Google ← الأمان ← التحقق بخطوتين ← كلمات مرور التطبيقات).
- **بريد الدومين** (info@rmt-cleaning.com): بيانات SMTP من لوحة الاستضافة.
- اضغط **«حفظ وإرسال إيميل تجريبي»**؛ تظهر النتيجة وسبب أي خطأ فورًا.
- كل طلب يُحفظ في «طلبات العملاء» مع عمود يوضح هل وصل الإيميل أم لا.

## الصفحات القانونية
تُنشأ تلقائيًا (عربي + إنجليزي): `/privacy/`، `/terms/`، `/cookies/` وتُعدّل من: الصفحات. النص قالب عام متوافق مع نظام حماية البيانات الشخصية؛ يُفضّل مراجعته مع مستشار قانوني قبل الإطلاق.

## المدونة (عربي)
- تُنشأ تلقائيًا صفحة `/blog/` مع 4 تصنيفات و4 مقالات مبدئية بالكلمات المفتاحية المستهدفة.
- إضافة مقال: مقالات ← أضف جديد. اختر **تصنيفًا** و**صورة بارزة** واكتب **مقتطفًا** قصيرًا.
- استخدم عناوين **H2 / H3** داخل المقال؛ يُبنى منها فهرس المحتويات تلقائيًا.
- صندوق **«السيو»** أسفل محرر المقال: عنوان ووصف لجوجل مع معاينة وعدّاد أحرف.
- غلافا مقالي المداخن والدكت رسومات مؤقتة بهوية الموقع؛ يُفضّل استبدالهما بصور حقيقية من أعمال المؤسسة.

## لو ظهرت صفحات 404
الإعدادات ← الروابط الدائمة ← اضغط «حفظ التغييرات» مرة واحدة (القالب يفعل ذلك تلقائيًا أيضًا عند دخول لوحة التحكم).

## قبل الإطلاق
- الإعدادات ← القراءة: تأكد أن خيار "منع محركات البحث" **غير مفعّل**.
- لوحة رفال ← السيو: أضف رمز Google Search Console ومعرّف GA4، ثم أرسل `/wp-sitemap.xml` في Search Console.
- لوحة رفال ← البيانات العامة: أضف خط العرض والطول من رابط الخرائط (يحسّن البحث المحلي).
- ارفع شعارات العملاء من تبويب العملاء.
- أكّد اعتمادات IRATA / LEEA / DROPS الفعلية (ملاحظة من ملف المحتوى).
- يُفضّل إضافة SMTP (مثل WP Mail SMTP) لضمان وصول إيميلات طلبات عرض السعر. كل الطلبات تُحفظ أيضًا في "طلبات العملاء".

## مقاسات الخطوط (من ملف الورد)
20pt عنوان الواجهة · 18pt عنوان الصفحة H1 · 14pt العناوين H2 · 12pt النص · 11pt النص الصغير.
تُعدّل من متغيرات `--fs-*` أعلى `assets/css/main.css`.
